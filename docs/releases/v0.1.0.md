The `v0.1.0` release is the first productized ToolX publish line.

- Stable core modules: `argtool`, `cfgx`, `asyncx`, `fsx`, `logsys`, `resultx`, `utils`, `sysx`, `hashx`, and `textcodec`.
- Bounded stable module: `httpx`, with TLS behavior depending on the selected backend.
- Experimental foundation: `tuix`, which is shipped in the source tree but is not part of the main first-release pitch.
- `cfgtool` is the first formal ToolX CLI contract and keeps the `cfgtool.result` / `schema_version=2` envelope for `0.1.x`.
- `cfgtool doctor` is included as the first operator-facing UX command for config preflight, validation, and repair guidance.
- `toolx-sync` is included as the scenario CLI with `toolx.sync.result` / `schema_version=1`.
- ToolX does not promise ABI compatibility in `0.1.x`; the release goal is source compatibility for the documented stable surface.
