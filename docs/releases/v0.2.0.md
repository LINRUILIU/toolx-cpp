ToolX `v0.2.0` expands the toolkit with additive APIs while preserving the
`v0.1.0` install and CLI behavior.

- New experimental `schemax` module with `Schema`, `Options`, `Issue`,
  `Compile`, `Validate`, and `ToCfgxIssues` on top of `cfgx`.
- `cfgtool validate`, `cfgtool doctor`, and `toolx-sync` now accept
  `--schema FILE`; schema validation failures return exit code `4` and add
  `schema_issues` to JSON output.
- `tuix` grows from foundation primitives into a small usable MVP with styled
  frame cells, theme data, gap/padding/flex layout controls, `Panel`,
  `TextInput`, `ListView`, and a config-inspector example.
- `asyncx` adds cooperative cancellation, task options, deadlines, and
  `TaskGroup` stats.
- `fsx` adds directory diff/sync planning, copy-tree batch actions, and a
  deterministic tar archive MVP. Zip archive support remains unavailable.
- `httpx` adds retry policy, circuit breaker state, safe file downloads, and
  multipart file upload helpers.
- `logsys` adds scoped structured context, trace spans, and logger metrics
  snapshots/reset.
- Installed CMake exports now include `toolx::schemax`; the install consumer
  verifies `schemax` plus a side-branch API.
- Added commented `examples/*_cookbook.cpp` executables for each public module;
  cookbook smoke tests run under CTest when examples and tests are enabled.

ToolX still does not promise ABI compatibility in `0.2.x`. The goal is source
compatibility for stable APIs unless a safety or correctness bug requires a
break. HTTPS behavior continues to depend on the selected `httpx` TLS backend
at build time.
