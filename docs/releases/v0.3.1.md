# ToolX v0.3.1

> Audience: ToolX users and package consumers
> Status: Latest tagged release note
> Applies to: `v0.3.1`
> Source of truth for: user-visible v0.3.1 release narrative

## Highlights

- Retained every filesystem undo operation produced by batch actions and
  finalized successful retained journals.
- Restored overwritten atomic-write/safe-replace targets in correct rollback
  order.
- Hardened tar extraction against Windows-rooted paths and destination escape
  through pre-existing symlinks.
- Recreated HTTP download temp files on every retry.
- Treated no-argument log messages as plain text instead of dynamic formats.
- Pinned GitHub Actions and verified the GoogleTest archive SHA-256.

## Compatibility

v0.3.1 was a compatible reliability patch. It did not remove or redefine
documented 0.3.x APIs or CLI fields.

## Build and dependency impact

Windows environment handling no longer confused case-insensitive `Path`/`PATH`
entries. GoogleTest remained test-only and fetched at its pinned version.

## Migration

No source migration was required. Applications relying on previously unsafe
archive extraction or download-retry behavior received stricter correctness.

## Known limitations

- Filesystem behavior still depends on platform permissions and filesystem
  semantics.
- Default packages still provide no TLS backend.
- No ABI guarantee was introduced.
