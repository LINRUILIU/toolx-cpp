ToolX `v0.3.1` is a compatible reliability and release-hardening update for the
`0.3.x` product line.

## Reliability and Safety

- `fsx` journals now retain every undo operation produced by a batch action,
  finalize successful retained journals, and refuse to roll back a completed
  transaction. Failed fail-fast runs clean up a journal only after local
  rollback succeeds.
- `fsx` rollback now restores overwritten atomic-write and safe-replace targets
  in the correct order.
- Tar extraction rejects Windows-rooted entry names and verifies that entries,
  including paths through pre-existing symlinks, remain within the destination
  root.
- `httpx::DownloadFile` recreates its temporary file for every retry so partial
  bytes from a failed attempt cannot be published with a later response.
- No-argument `logsys` messages are treated as text rather than as dynamic
  printf format strings.

## Build and Release Hardening

- Windows/MSVC configuration no longer mistakes the case-insensitive `Path`
  environment variable for separate `Path` and `PATH` entries.
- GitHub Actions are pinned to immutable revisions and the GoogleTest download
  is verified with SHA-256.

This release preserves the public `0.3.x` source compatibility boundary.
