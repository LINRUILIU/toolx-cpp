ToolX `v0.3.2` is a compatible reliability patch for the `0.3.x` product line.

## Deterministic Proxy Control

- `toolx-http check` adds `--no-proxy-from-env`; manifests may set the optional
  root `use_proxy_from_environment` boolean. The default remains `true`, and
  the CLI flag has highest priority to disable environment proxy handling.
- `toolx-sync` adds the same flag for the HTTP client used by `--remote-url`.
  It is accepted without a remote URL and has no network side effect in that
  case.
- Both CLI JSON contracts add `data.proxy_from_environment` without changing
  their existing envelope schemas.

## FSXJ3 Recovery Ordering

- Configured `fsx` journals now use synchronized `FSXJ3` write-ahead undo
  records before every destructive primitive mutation. Header, undo records,
  and `COMMIT` are persisted before normal cleanup.
- FSXJ3 recovery will not overwrite a destination that appeared after the
  journal entry; it reports a conflict and keeps the journal and files for
  inspection. `FSXJ1` and `FSXJ2` recovery compatibility remains intact.
- This improves recoverable ordering only. It does not claim universal
  power-loss atomicity across filesystems, drive caches, or cross-device moves.

## TLS and CI

- CI adds a dedicated Linux/OpenSSL `httpx_tests` job. Default builds and
  release packages remain free of a TLS backend dependency.
- The OpenSSL test suite generates a temporary loopback certificate and private
  key at runtime, trusts only the generated public certificate as its CA file,
  verifies `localhost`, and rejects a hostname mismatch. No private key is
  tracked in the repository.

The release preserves the public `0.3.x` source compatibility boundary.
